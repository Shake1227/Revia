# ブランド

- **表示名** Revia
- **技術上の名前** `revia`
- **タグライン** Scattered projects, one calm workspace.

複数のローカルプロジェクトと GitHub リポジトリを一つの画面から管理する、落ち着いたデスクトップ開発ツールです。

## デザインの考え方 — 宵（よい）

月明かりの湖と霧の山並みを背景に、半透明のシートを浮かべます。ウィンドウの上部は景色がそのまま見える帯で、画面のタイトルや件数は空の上に置き、一覧や差分などの本文だけをシートに載せます。

- **景色** 既定は、時刻で移り変わる湖。夜明け、朝霧、昼、夕焼け、宵、夜を 1 日でたどり、空の明るさと、太陽と月の位置が変わる。時刻はこのコンピューターの時計に合わせるか、設定で好きな時刻に止められる。ほかに星霧、無地、利用者が選んだ画像。景色は写真のように見えることを目指し、`scripts/make-backdrops.py` が計算で描く（写真や外部の素材は使わない）。山並みは奥行きを持った地形として描き、手前の稜線が奥を隠し、遠い山ほど霞む。湖は、空と山を波の傾きでゆがめて映す。1 日のうち 11 の時刻を描いておき、アプリは近い 2 枚を重ねて、あいだの時刻を作る。時計に合わせているあいだは、1 分ごとに次の位置と色へ 1 分かけて移すので、止まって見えない。時刻を選び直したときや、しばらく離れて戻ったときは、途中の時刻をたどりながら移る（太陽や月は弧に沿って動き、空の色も順に変わる）。
- **太陽と月** アプリが描き、山の後ろから昇って空の高いところを通る。太陽は、空を染める光と放射状の光の筋をまとった白い円盤で、低いほど赤く大きい。月は模様のある満月で、冷たい色の淡い暈だけをまとう。水面には、太陽は広い金色の、月は細い銀色の光の帯を落とす。
- **風** 雲と霧は風下へ流れ、さざ波が動き、月や太陽の下の水面がきらめく。ふだんは穏やかで、ときどき突風が吹く。突風のあいだは雲・霧・さざ波が速まり、光の筋と花びらが空を横切り、淡い光の帯が湖を渡る。夜は星が瞬き、湖畔に蛍が出て、ときどき星が流れる。一括操作がうまく終わったときは流れ星を一つ流す。ウィンドウが非アクティブのときと「動きを減らす」設定のときは止める。
- **空の上の文字** 見出しや件数は空の上に直接置くので、テーマではなく空の明るさに合わせた配色にする（昼は濃い文字、夜は淡い文字）。テーマで「空に合わせる」を選ぶと、シートも空の明るさに合わせてライトとダークが切り替わる。
- **色** 夕映えから藤色へ移るグラデーション（`--brand-1` → `--brand-3`）をブランドの色とし、選択中の印や進行表示にだけ使う。主ボタンは月明かりの乳白色（ライトでは墨色）。状態の色は意味で固定し、色だけでなく形でも区別する。色付きの丸い下地、発光、色を敷いたラベルは使わず、状態は線の印と文字で示す（色を付けるのは競合とエラーだけ）。
- **構成** 左に浮かぶドック（画面の切り替えと、お気に入りへの近道）、上部中央にコマンドバー、本文はシート。枠で囲むのではなく、余白・文字の大きさ・色で重みを付ける。
- **文字** 既定は IBM Plex Sans JP（英数字も同じ書体）、コードやパスは IBM Plex Mono。画面のタイトルと件数の数字も同じ書体で、太さと大きさで差を付ける（明朝体は使わない）。設定で M PLUS 2 か OS の書体に切り替えられる。IBM Plex と M PLUS 2 はアプリに同梱し、OS による見た目の差をなくす。
- **動き** 画面を切り替えると見出しが空に浮かび、シートが下からせり上がる。数字は数え上げ、主ボタンには光が一度だけ走り、成功した行には光の帯が通る。等速の動きや意味のない繰り返しは使わない。
- **ロゴ** 幹から枝が分かれて戻り、もう一本が先へ伸びる。節でつながった枝がそのまま「R」になっている。元データは `src/assets/brand/symbol.svg`。アプリのアイコンは、夜の湖（星空、満月、雲、山並み、水面に映る月の光）の上にこのロゴを置く。景色は `scripts/make-app-icon.py` が `src-tauri/icons/source/app-icon.png` に描く。既定は形を整理した絵（`--style stylized`）で、`--style realistic` にするとアプリの背景と同じ原板（21 時の空・雲・山と湖）と月の画像から写実的に組み立てる（numpy と Pillow が必要。背景を描き直したら、このスクリプトも実行する）。スクリプトは、macOS の決まりに合わせて周りに余白を取った `app-icon.png` と、枠いっぱいに描いた `app-icon-full.png` の 2 枚を書き出す。各サイズは `npx tauri icon <画像> -o <一時フォルダ>` で作る。macOS の `icon.icns` は `app-icon.png` から、Windows と Linux で使う `icon.ico`・`32x32.png`・`128x128.png`・`128x128@2x.png`・`icon.png` は `app-icon-full.png` から作って `src-tauri/icons/` に置く（余白があると、Windows のタスクバーなどでほかのアプリより小さく見えるため）。
- **解像度の低い画面** 表示倍率が 1.5 倍に満たない画面（Windows の 100% など）では、文字の大きさを 0.5px 刻みから 1px 刻みに切り上げ、アイコンの線を少し太くする。半端な大きさの文字や 1px に満たない線は、こうした画面ではにじんで見えるため。

## 言葉

- 状態名と操作名は、ボタン・メニュー・確認画面で同じ言葉を使う。Git の用語（Push、Pull、Fetch、Merge）はそのまま使い、必要な説明はツールチップで補う。
- 短く、自然に。丁寧すぎる言い回しや説明の重ね書きを避ける。
- エラーは原因と対処を伝える。
